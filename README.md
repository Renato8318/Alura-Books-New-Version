# 📚 AluraBooks - New Version


**AluraBooks** é uma aplicação web desenvolvida como projeto prático para aprender a manipular dados de uma API usando **JavaScript**. O foco principal do projeto está no uso de métodos de array e na interação com o **DOM** para exibir livros de tecnologia de forma dinâmica e interativa.  


## 🚀 Funcionalidades  


- 📋 **Exibição de Livros**: Exibe uma lista de livros no **DOM** com informações como título, autor e preço.  
- 🗂️ **Filtragem por Categorias**: Filtra livros por categorias, como **Front-end**, **Back-end**, **Dados** e **Disponíveis**.  
- 🔀 **Ordenação**: Ordena os livros com base em diferentes critérios, como **preço** ou **popularidade**.  
- 💰 **Cálculos Agregados**: Calcula o **total do preço dos livros disponíveis**.  


## 🛠️ Tecnologias Utilizadas  


- **HTML5** 🏗️  
- **CSS3** 🎨  
- **JavaScript** ⚡  
- Manipulação do **DOM** 🌐  
- Métodos de array como:  
  - `forEach`  
  - `map`  
  - `filter`  
  - `reduce`  
  - `sort`
